# Student Marks Analyzer

A beginner-friendly Python project that calculates a student's total marks, percentage, grade, and pass/fail result.

## Features

- Takes student marks as input
- Calculates total marks
- Calculates percentage
- Assigns grade
- Determines PASS/FAIL result
- Displays a clean summary

## Technologies Used

- Python
